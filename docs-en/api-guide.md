# API Guide for Ollama Text Translation 

## Overview  
This document serves as a guide on how to perform text translations using the Olmaa AI platform. It covers installation, model downloading and basic usage of its APIs.   

### Installation Steps    
#### Step 1: Installing Olivermamai (Ollama)
First you need to install Ollama in your system environment :  
```json
{
  "model": "exaone3.5:7.8b",
  "created_at": "2023-08-04T08:52:19.385406455-07:00",
  "response": "Hello",
  "done": true
}
```   
#### Step 2: Downloading the Model  
Downloads an exaone3.5 model for translation purposes :    
`bash olma pull exaone3.5@7.8B `
